講義

河合勝彦が担当する講義の専用サイトです。授業の案内、出席確認、教材、ブラウザで使える実習環境などは、各講義サイトに掲載しています。受講者のみなさんは、講義で指示されたサイトを利用してください。

2026年度 担当講義

情報システム論 NCU IS2026

2026年度出席確認①〜㉚プログラミング入門30日JupyterLab

出席確認（AIに関するクイズ）、ブラウザだけで使える Python / Jupyter 実習環境、操作しながら考える体験型教材、地図・データ可視化のデモ、JavaScript / Python のサンプルコード・チュートリアルをまとめた講義サイトです。HTML・CSS・JavaScript・Python を1日1テーマで学ぶ「プログラミング入門30日」も公開しています。

講義サイトを開く GitHub

経営情報 MIS 2026

2026年度生成AI演習全15回オンライン

「情報を読み、経営を動かす。」データ・情報技術・生成AIをテーマに、経営を支える情報の役割を理論と実践の両面から考える講義です。毎回の演習で生成AIを実際に使い、その出力を検証しながら、AIを「使いこなす側」に立つための知識と判断力を養います。授業概要・講義予定・お知らせ・出席確認・プログラミング入門を掲載しています。

講義サイトを開く GitHub

基礎演習Ⅱ Basic Seminar II 2026

2026年度 後期経済学部水曜3限全15回生成AI活用

経済学部「基礎演習Ⅱ」の授業サイトです。生成AIを活用したアカデミック・ライティング（探究の基礎）、企業と連携した店舗設計提案プロジェクト（実践プロジェクト）、キャリア講習の3つのフェーズで構成しています。授業計画、各回の内容と資料、生成AI利用ガイド、成績評価の案内を掲載しています。

講義サイトを開く GitHub

企業診断ＡＢＣ KSABC 2026・河合担当分

2026年度 後期第6〜10回月曜2限全5回Teams

「企業診断ＡＢＣ」のうち、河合勝彦が担当する第6〜10回（11月2日〜11月30日）の講義サイトです。ソーシャルメディア、生成AI、ネットワーク、XテックとDX、Society 5.0 とスマートシティの5つのテーマを通じて、企業や組織における情報活用の最近の潮流と、その理論的背景を学びます。授業概要、講義予定、各回の講義ページ、評価・受講のしかたを掲載しています。

講義サイトを開く GitHub

受講者のみなさんへ

出席確認の方法、課題の提出先、授業に関する最新のお知らせは、それぞれの講義サイトで案内します。講義サイトの内容は授業の進行にあわせて随時更新されますので、受講中は定期的に確認してください。

プログラミングの自習教材や実習環境は、研究室の 研究成果 のページでも公開しています。あわせてご活用ください。
